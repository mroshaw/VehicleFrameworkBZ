# Vehicle Framework BZ

This mod is an **unofficial** port of the amazing [Vehicle Frameworks Subnautica](https://www.nexusmods.com/subnautica/mods/859) mod by [NeisesMike](https://github.com/NeisesMike), for the Below Zero game.

You can use existing Subnautica custom sub mods directly, there is no need to look for "Below Zero" versions of the vehicles themselves. Just extract them into your Below Zero `BepInEx\plugins` folder like you would any other mod.

Tested with:

- [The Odyssey](https://www.nexusmods.com/subnautica/mods/871)
- [The Crush Drone](https://www.nexusmods.com/subnautica/mods/1654)

More vehicles will be tested and added to the list above.

## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod!*

All of my mods are open source, and you can find the full source code in my [Subnautica Mods GitHub Repository](https://github.com/mroshaw/SubnauticaThunderKitMods).
